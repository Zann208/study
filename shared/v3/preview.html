Key ideaThe root bridge is the switch with the lowest bridge ID: priority first, then MAC address.
ExampleSW1 32768.0011 beats SW2 32768.0022 because the MAC is lower.
RememberEvery non-root switch has exactly one root port.
WarningChanging the priority on a production switch triggers a topology change.
Lowest cost wins, not highest bandwidth number.Cost is inverse to bandwidth; read the table direction carefully.
Designated portThe port on a segment with the best path to the root; it forwards for that segment.
